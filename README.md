# Initial — HTML & CSS Grid Practice Project

🔗 **Live Demo:** https://olfateme.github.io/project-3/

A landing page built with **HTML5** and **CSS3** as my third practical project while learning Front-End Development.

## 📌 About The Project

This project was created as a hands-on exercise to learn and practice **CSS Grid**.

The main goal was to understand how Grid works and apply it to build structured layouts and different sections of a complete landing page.

The project is based on the **Initial** landing page design and was developed for learning and practice purposes.

## 🛠️ Technologies

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Font Awesome
* Google Fonts
* Git & GitHub
